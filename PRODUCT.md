## Platform
web
## Product
A 20-minute robotics simulation MVP: command a robot arm to sort one block onto a platform, and observe physical success.
## Audience and use
A user exploring fast AI-driven robotics through a polished interactive browser demo.
## Core flow
Enter command, interpret via Cerebras, execute bounded action, observe block settling on target. Reset repeatably.
## Confirmed direction
Bright clean robotics studio. One robot arm, one scene, one task. Scale priority: faster AI decisions.
